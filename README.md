# Auranza — Digital Agency Website

A premium, responsive agency website built with Next.js 14, React, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Import `auranzadigital-sys/AURANZA` from GitHub in Vercel.
2. Keep the framework preset as **Next.js**.
3. Use the default build command `npm run build`.
4. Click **Deploy**.

## Before going live

- Replace the placeholder contact email `hello@auranza.com` in `app/page.tsx` with your real business email.
- Add your actual WhatsApp number/social links when available.
- Update the metadata URL in `app/layout.tsx` once your domain is final.
- Add real client projects and testimonials only when you have permission and verified details.

The portfolio and testimonial areas are intentionally not populated with invented client claims.
